## 定義・系列上の注意
1. 本系列は報告日に集計された新規陽性者数であり、感染日別の発生数ではない。
2. 厚生労働省の注記によると、2020-05-08公表分から、国内事例（チャーター便を除く）のデータソースは厚労省が把握した個票の積上げから、各自治体ウェブサイト公表数の積上げへ変更された。
3. 新規陽性者数は自治体が公表した個別事例数（再陽性例を含む）の積上げであり、前日の累計値との差分とは一致しない場合がある。
4. 2021-09-13以降は、自治体公表値とHER-SYS値の期間別併用が始まった。報告後14日までと15日目以降でデータの扱いが異なるため、長期比較では構造変化に注意する。
5. 2022-09-27にHER-SYSに基づく集計方法へ変更された。変更日をまたぐ分析では系列の定義・収集方法の変化を考慮する。
6. 2020-05-08のCSV値は88。過去の照合で同日の厚労省発表資料に80という値が確認されているが、本ファイルでは公式CSVの値を保持し、手動修正していない。
7. 大きな日次値や報告上の変動は独断で除外・平滑化・補正しない。
