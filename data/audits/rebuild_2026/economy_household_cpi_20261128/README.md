家計調査は家計収支編・二人以上の世帯の月次表を採用対象候補として取得した。CPIは2020年基準・全国・月次。必要月数は、長期系列とCPIは2017年1月～2024年12月、全品目表は各ファイルの公表期間全体。2015年改定と2020年改定の全品目表は別ファイルのまま保全した。数値の加工、分析、正式採用判定は実施していない。

全8件をCP932のCSVとして厳密に読み込み、行の列数、年月ラベル、月軸全体の連続性、対象月の収録を確認した。保存版の容量とSHA-256をマニフェストと照合し、確認時の別取得コピーともバイト一致を確認した。月が収録されていても、個別品目には空欄があり得る。品目単位の利用可能性や改定をまたぐ比較可能性は次工程の確認事項。

出典は総務省統計局「家計調査」「消費者物価指数」、配布はe-Stat。e-Stat利用規約の出典表示・第三者権利に関する条件を確認し、対象の公表統計CSVを取得時のバイト列のまま収録した。ファイル別の出典・直接URL・取得日時（JST）・SHA-256は [マニフェスト](source_manifest.json) に記録。原本は `data/raw/economy/household_cpi_20261128/` に保存した。[家計調査公式掲載元](https://www.stat.go.jp/data/kakei/longtime/index.html) · [CPI公式掲載元](https://www.stat.go.jp/data/cpi/) · [e-Stat利用規約](https://www.e-stat.go.jp/terms-of-use)

## 再取得

リポジトリ直下から、未使用のキャッシュ・マニフェスト名を指定する。標準ライブラリのみで動作する。同じキャッシュで再実行するとURL・SHA-256を確認して再利用し、不一致や台帳欠損は競合として報告する。配布元の時系列は更新されるため、将来の取得内容は今回の保全版と異なる場合がある。

```bash
mkdir -p /tmp/household-cpi-check
python scripts/acquire_household_cpi.py /tmp/household-cpi-check/raw /tmp/household-cpi-check/manifest.json
PYTHONPATH=scripts python -m unittest discover -s tests -p test_household_cpi.py -v
```

取得不能時はマニフェストのHTTP状態・失敗理由を確認する。公式経路の候補は統計局掲載ページからのe-Stat現行表リンクと、CPI掲載表にあるe-Statデータベース表示。今回の8件はCSV配布で成功したため、代替経路での取得は不要だった。
