- 研究根拠：各研究の抽出CSV、全文抽出監査、2026-11-26原資料整合性監査
- 位置づけ：研究から確認された問題を、軽減策と評価可能な指標へ接続するための分析用マトリクス。介入効果の実証結果ではない。

## 1. 作成方針

本表は、各倫理的問題について次の区分を明示する。

1. **確認された問題**：原著の調査結果・質的カテゴリー・実践記述に基づく。
2. **研究内で報告された対応**：参加者が実際に行ったと報告した対応、または施設で実施されていた方法。
3. **著者提案**：原著の考察・結論に記載された提案。効果検証済み介入とは扱わない。
4. **本研究で追加提案する軽減策**：今回の研究目的に照らした分析上の提案。原著が実施・検証したと誤認しない。
5. **評価指標**：軽減策を将来評価するための候補。現時点で測定済みの結果ではない。

## 3. 評価設計上の共通ルール

- 指標は軽減策の実施状況（process）、短期的な変化（outcome）、意図しない不利益（balancing measure）を分けて設計する。
- 面会実施率だけでなく、面会を希望したが実現しなかったケース、不可理由、代替策、患者・家族の希望との一致を記録する。
- 対面・窓越し・遠隔を同じ「面会」として一括しない。複数手段を使った場合は併用を記録する。
- 患者、家族、看護師、感染管理者、施設の単位を混同しない。分母は項目ごとに保持する。
- 質的研究のカテゴリーを頻度・割合に変換しない。
- 観察研究の前後変化を、そのまま介入の因果効果と解釈しない。感染流行度、患者重症度、人員配置、病棟機能等を併せて記録する。
- 本表の評価指標は提案であり、7研究が実測した値ではない。

## 4. 対応する倫理原則

- 自律：本人の意思確認、説明・理解、代理判断の透明性。
- 尊厳：身体的接近、看取り、患者らしさ、死別後の扱い。
- 公平性・正義：デジタル格差、面会判断の一貫性、資源配分。
- 比例性・必要性・害の最小化：感染対策と面会ニーズの個別評価。
- 手続的公正・透明性・説明責任：基準、例外、再評価、判断理由の記録。
- 互恵性：医療従事者の心理的安全性・業務負担への組織的対応。

## 5. 証拠の限界と次の研究課題

1. 7研究の対象・方法・調査時期は異なる。割合を単純比較しない。
2. 立野らは施設運用・専門職意識の調査であり、患者・家族本人の心理的アウトカムではない。
3. 西口ら・松本らは医療従事者の質的経験を示す。カテゴリー数は有病率・発生頻度ではない。
4. 下村らは5名の回顧的質的研究で、オンライン面会の有効性・対面との同等性を証明しない。
5. 石原らは治療説明・同意の研究であり、面会制限そのものの効果研究ではない。患者23/45の複合回答を意思能力欠如や治療拒否と解釈しない。
6. 白石らの電子付録5件は個別内容未確認。付録依存の質問票詳細・数値は未確定。
7. 今回の7研究だけでは、希少資源配分と非COVID患者アクセスの倫理的問題を十分に評価できない。別の一次資料群が必要。
8. 本表の軽減策は「研究内の実践」「著者提案」「本研究の追加提案」を区別した。介入効果が検証されたとする記述は含めていない。
