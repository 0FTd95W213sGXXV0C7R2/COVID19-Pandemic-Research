- 研究デザイン：横断質問紙・混合研究。2病院の職員、複数企業の非医療従事者等を対象とし、配布3,191件、回収1,520件。
- 本文で確認できた主な報告値：救命数最大化原則への賛成95.8%、一定期間以上の便益を重視する原則82.2%、ライフサイクル原則80.1%、医療従事者への報償・優先75.3%、人工呼吸器の取り外し・再配分64.4%、先着順28.4%。

## 2. 初回の統合所見（研究上の仮説であり、確定結論ではない）
1. 規範資料は、患者意思、医学的適応、公平性、多職種協議、記録、倫理支援を共通論点とする。ただし治療中止・再配分の許容範囲や救命可能性の判定方法には争点が残る。
2. 実証資料は、配分原則への意識（Norisue）、単施設の意思決定過程（Ishizaki）、高度救命救急センターの施設調査（Mori）という異なる観測対象を持つ。実際の配分率として統合してはならない。
3. 重要な検討点は、①救命可能性の予測誤差と差別、②年齢・ADL・障害・社会的背景、③本人意思・家族の推定意思と緊急時同意、④治療中止と資源再配分の倫理的・法的区別、⑤地域間搬送・広域調整、⑥判断責任の個人化と医療者負担、⑦記録・説明・異議申立て・事後検証である。
4. ガイドラインや倫理相談の効果は現時点の観察データだけでは証明されていない。Moriの内部ルール有無と治療制限・心理的負担の差は記述的関連であり、因果解釈しない。

### 5.2 共通する基本原則

両提言は、少なくとも次の点で共通する。
1. 非常時でも医学的適応と患者本人の意思を判断の中心に置く。
2. 配分や治療差し控え・中止を個人の独断にせず、医療・ケアチームで検討する。
3. 患者の意思または推定意思、公正性を考慮する。
4. 判断過程を診療録等に記録し、透明性・検証可能性を確保する。
5. 患者・家族への説明や意思共有を可能な限り行う。
6. 治療を差し控え・中止する場合にも緩和ケアを含む適切な医療を継続する。
7. 医療施設が事前に体制・手順を整備する。

### 5.4 解釈上の重要な留保

- 生命・医療倫理研究会提言の「払底」定義は、院内の機器不足だけでは足りず、他院移送・調達努力を尽くした状態を想定する。これは、資源不足の程度に応じてトリアージを限定する考え方であり、単に病院内で満床・満機器となった時点で再配分を始める趣旨ではない。
- 同提言は、人工呼吸器再配分を「許容されうる」とする一方、各病院の事前ポリシー、原則としての倫理委員会等の検討・承認、救命可能性の明確な差、差が不明な場合の既装着患者優先、本人同意等の条件を置く。これらの条件を省略して「再配分を推奨した」と要約してはならない。
- 同提言は、救命可能性の高い患者を優先する考えと、属性等による差別的順位付けを禁止する考えを併記する。重症度指標の妥当性・予測誤差、障害や年齢等の変数が指標に入り込む可能性は、別途検討が必要である。
- JSICM提言は7項目からなる簡潔な枠組みであり、生命・医療倫理研究会提言ほどの運用アルゴリズムを提示していない。両者の違いを「矛盾」と即断せず、文書の目的・性格・具体性の差として扱う。
- いずれも規範的提言であり、現場で実際にその手続がどの程度実施されたか、患者転帰や公平性を改善したかを示す実証研究ではない。

### 5.5 JSICM PDFの書誌上の不一致

- PDFの日本語著者欄（p.509）では、著者として「丸藤 哲*2」が記載される。
- 同じPDFの英語書誌欄（p.510）では、対応する著者位置に「Satoshi Gando *2」と記載されている。
- 日本語欄と英語欄で著者名が一致しないため、現時点では日本語著者欄・J-STAGE書誌を優先して記録しつつ、出版社への照会または別の正式書誌での確認が必要な不一致として保持する。黙って一方を修正・統合しない。
- なお、日本語著者欄は「丸藤 哲*2」、英語欄は「Satoshi Gando*2」となっていることを原文上の観察事実として記録する。正しい著者がどちらかは本監査だけでは確定しない。
