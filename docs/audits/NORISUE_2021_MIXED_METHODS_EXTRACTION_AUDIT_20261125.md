## 1. 研究目的・デザイン

日本の医療従事者と非医療従事者が、パンデミック時の人工呼吸器配分原則にどの程度賛成するかを、質問紙の量的分析と自由記述の質的分析で調べた横断研究。

| 項目 | 抽出結果 |
|---|---|
| デザイン | 自記式横断質問紙・混合研究 |
| 調査時期 | COVID-19第一波後（2020年） |
| 医療機関 | 都市部の三次病院1施設（330床、東京中心部から約10km）、郊外の三次病院1施設（420床、横浜中心部から約30km） |
| 非医療機関 | 医療物資を寄付した匿名企業5社（化粧品、電子機器、ホテル、娯楽、製薬） |
| その他の対象 | 病院外来を訪れた患者・家族等にも紙またはオンラインで配布 |
| 対象年齢 | 16歳以上 |
| 配布数 | 3,191件と本文に記載 |
| 回答数 | 1,520件と本文に記載 |
| 質問紙 | 日本語版・英語版を補足資料に収録。四件法と自由記述 |
| 量的分析 | 賛成／反対の二値化、群間比較、一般化線形モデル、探索的因子分析 |
| 質的分析 | 自由記述を2名が分析。既存10テーマによる演繹的分類後、帰納的内容分析で新規テーマを抽出 |
| 倫理審査 | 参加2病院のInstitutional Review Board |

**対象集団の注意：** 全国確率標本ではない。病院職員、企業従業員、外来患者・家族等を組み合わせた便宜的サンプルであり、「日本国民全体の意見」や「社会的合意」を直接表すものではない。

## 2. 質問紙の構造（補足資料実体確認）

補足PDFにはe-Appendix 1（日本語版）、e-Appendix 2（英語版）、e-Appendix 3（自由記述テーマ）が含まれる。

### 2.1 配分原則に関する設問

主な配分原則4項目：
1. **救命可能性（save the most lives）**：人工呼吸器で回復する可能性が高い人を優先。
2. **ライフサイクル（life cycle）**：人生の各段階を経験できる機会を考慮し、より若い人を優先。
3. **便益の持続期間（ensure minimum duration of benefit）**：治療後により長く生存する可能性が高い人を優先。
4. **医療従事者への報償・優先（reward and guarantee）**：感染症・災害対応の最前線で働いた人を優先。

追加設問：
5. すべての人工呼吸器が使用中の状況で、より優先度の高い新規患者のために、優先度が低い既装着患者の人工呼吸器を中止・再配分することへの賛否。
6. 患者の優先度評価を行わず先着順（first come, first served）で配分することへの賛否。

各設問は「非常に賛成／賛成／反対／全く反対」の4件法で、各項目に自由記述欄がある。

### 2.2 背景項目

Q7〜Q20の14項目：
- 職業（病院職員／非病院職員、病院内職種）
- 年齢、性別、婚姻状況、同居家族
- 介護者であるか、経済的扶養者の有無
- 人工呼吸器治療歴、親しい家族の死の経験
- 慢性疾患、過去1年の入院回数
- 自己評価による余命、世帯年収、最終学歴

Q21は追加の自由記述欄。

### 2.3 調査票の提示文・測定上の注意

- 回答者には、医療現場でどの判断原則が妥当かという観点から回答するよう求めている。
- 優先順位は医師個人の価値観・秘密の判断ではなく、透明性があり一般市民の価値観を反映すべきだという趣旨を提示している。
- 調査票は既存の妥当性確認済み尺度を特定できなかったため研究者が作成。医療従事者・非医療従事者のパイロットテスト後に改訂。
- 10人の生命倫理専門家が内容妥当性を評価。CVI平均は関連性0.821、明瞭性0.902、CVRは0.742。
- 探索的因子分析では4つの個別優先原則が第1因子に含まれたが、Cronbach's αは0.5002。先着順は別因子、人工呼吸器の取り外し・再配分はどちらの因子にも属さなかった。
- 著者は項目が異なる原則への賛否を個別に測る設計であることを説明している。したがって6項目を一つの単一尺度として合算しない。

## 3. 標本・回答率・分母の監査

本文から確認できる値：
- 配布数：3,191件。
- 回答数：1,520件と記載。
- 病院職員群：854人、非病院職員群：666人。
- 群別の配布数：病院職員1,756件、非病院職員1,436件。
- 群別回答率：病院職員49%（854/1,756）、非病院職員46%（666/1,436）。
- 職業情報が不完全な回答21件を除外した後の全体回答率は48%と記載。
- 職業群別の回答率に有意差なし（P=.82）と報告。

**要再確認の分母不整合：**
- 群別配布数1,756＋1,436＝3,192であり、本文記載の全配布数3,191と1件ずれる。
- 病院職員854＋非病院職員666＝1,520で、本文記載の回答数と一致する一方、本文には職業情報不完全の回答21件を除外したとの説明がある。
- Table 1の群別構成比は病院職員55.4%、非病院職員43.2%で合計98.6%となり、残り1.4%の扱いを表の抽出テキストだけでは確定できない。
- したがって、回答者総数・職業分類済み数・回答率計算対象の関係は原PDFの表・本文の再確認事項として残す。今回の監査では数値を推測して補正しない。

## 4. 量的結果の抽出

### 4.1 全回答者の賛成割合

| 配分原則 | 賛成割合 | 指標の意味 |
|---|---:|---|
| 救命可能性を高める（save the most lives） | 95.8% | 現在の疾病から救命される可能性 |
| 便益の最低持続期間を考慮 | 82.2% | 治療後の生存期間の見込み |
| ライフサイクル | 80.1% | 人生の各段階を経験する機会 |
| 最前線の医療従事者を優先 | 75.3% | パンデミック対応への貢献 |
| 先着順 | 28.4% | 個別の優先度評価をしない方式 |
| 人工呼吸器の中止・再配分 | 64.4% | より優先度の高い新規患者へ再配分する案 |

これらは配分原則への回答者の賛否であり、実際の臨床配分行動・政策採用・社会全体の合意を示す値ではない。

### 4.2 病院職員と非病院職員の比較

| 原則 | 病院職員 | 非病院職員 | P値 |
|---|---:|---:|---:|
| 救命可能性 | 97.7% | 93.4% | <.001 |
| ライフサイクル | 82.9% | 76.9% | .005 |
| 便益の最低持続期間 | 84.8% | 78.8% | .003 |
| 最前線従事者への報償・優先 | 70.7% | 80.5% | <.001 |
| 先着順 | 27.3% | 29.4% | .29 |
| 中止・再配分 | 67.6% | 60.8% | .01 |

群間差は質問紙回答の比較である。病院職員群・非病院職員群は無作為抽出された集団ではないため、職業属性そのものが賛否の差を生じさせたという因果解釈はしない。

### 4.3 調整モデル・因子分析

- 年齢、性別、病院職員か否か等を調整した一般化線形モデルを実施。
- 病院職員は「救命可能性」への賛成が高い（調整OR 2.27、95%CI 1.21–4.24、P=.01）。
- 病院職員は「最前線従事者への報償・優先」への賛成が低い（調整OR 0.63、95%CI 0.47–0.83、P<.001）。
- これらは調整後の関連であり、職業が意見を引き起こしたことを示す因果効果ではない。
- 4つの個別優先原則のαは0.5002であり、複数の倫理原則を一つの潜在尺度として扱うことには慎重さが必要。
- 人工呼吸器の中止・再配分設問は、他の優先原則と同一の因子に属さなかった。

## 6. 研究上の含意

1. **透明性・事前準備への支持と必要性**：自由記述では、基準の公開、事前の周知、地域・全国レベルの調整、家族への説明が繰り返し論点となった。
2. **複数原則の調整**：救命可能性、ライフサイクル、便益の持続期間、最前線従事者への優先は、それぞれ別の倫理的理由を持つ。単一スコアに安易に統合しない。
3. **再配分への賛成と倫理的懸念の併存**：全体の64.4%が再配分に賛成した一方、再配分目的の人工呼吸器中止の道徳的許容性に関する自由記述が45件あり、心理的負担への懸念も確認された。賛成率だけで社会的合意と判断しない。
4. **集団間の意見差**：医療従事者は救命可能性を重視する割合が高く、最前線従事者への優先を支持する割合は非病院職員より低かった。職業集団の内部にも多様性があり、医療従事者を単一の価値観で代表させない。
5. **社会的役割・人口動態の論点**：介護者・社会的役割、人口減少・生産年齢人口への優先といった意見が出た。これらは実際の臨床基準として妥当と証明されたわけではなく、差別・公平性の観点から批判的に検討すべき意見として扱う。
6. **家族の立場と公益の緊張**：公共のために再配分を理論上支持しても、自分の家族に適用されると受容しにくいという回答が報告された。制度の社会的受容には、本人・家族への説明や心理的支援が必要となる可能性がある。

## 7. 本研究で測定していないこと

- 実際の人工呼吸器配分・中止・再配分の実施件数や患者転帰。
- ICU入室、ECMO配分、病床配分の実績。
- 回答者の賛否が実際の危機時の行動に結びつくか。
- 全国代表性のある世論。
- 家族・患者の経験を独立に深掘りする面接データ。
- 倫理相談、施設ルール、心理支援の有効性。
- 配分原則の実装による公平性・救命率の改善。

## 8. 本研究の採否・研究領域への接続

| 研究領域 | 採用用途 | 採用してはならない用途 |
|---|---|---|
| ① 希少資源配分 | 人工呼吸器配分原則に関する医療従事者・非医療従事者の意識、再配分への賛否、透明性・公平性への懸念 | 実際の配分実績、全国的合意、臨床効果 |
| ② 患者・家族の自律性と尊厳 | 再配分に伴う家族の心理的負担・本人の価値観への懸念 | 患者・家族本人の直接的な経験調査 |
| ③ 非COVID患者アクセス | 非COVID患者も人工呼吸器を必要とし得るという調査票上の問題設定 | 非COVID患者の受診・治療遅延の実測値 |
| ④ 医療従事者の負担と相互扶助 | 判断の客観性、医療者の心理的外傷、複数職種合意への期待 | 実際の医療者の心理的負担率・介入効果 |

**採用判定：** 規範的意識・受容度に関する混合研究として採用。Mori（施設実態調査）・Ishizaki（単施設の意思決定過程）とは観測対象が異なるため、数値を統合せず三角測量に使用する。
