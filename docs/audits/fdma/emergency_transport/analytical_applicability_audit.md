## 1. 結論

**限定付きで補助指標として使用可能。非COVID患者の医療アクセスを直接測定する主アウトカムとしては使用不可。**

このデータが直接表すのは、対象消防本部において「医療機関への受入れ照会4回以上」かつ「救急隊の現場滞在30分以上」となった救急事案の件数である。これは救急受入れ調整の困難・遅延を示すが、患者の受療拒否、未搬送、治療中断、非COVID診療の制限そのものを測る指標ではない。

消防庁の公表注記では、調査対象の搬送困難事案のうち医療機関へ搬送できなかった事案はないとされている。したがって、搬送困難件数を「救急搬送拒否件数」や「未治療患者数」と読み替えてはならない。一方、搬送先決定までの困難・現場滞在の長期化は、救急医療提供体制への負荷を示すため、背景指標として有用性がある。

## 2. 調査定義と対象

### 2.1 事案定義

消防庁資料で確認できる定義：
- 医療機関への受入れ照会回数：4回以上（4回目で搬送先が決定した事案を含む）
- 現場滞在時間：30分以上（現場到着から現場出発まで）
- 上記2条件を同時に満たす事案

「4回以上」と「30分以上」はAND条件である。片方のみを満たす事案は、この指標に含まれない。

### 2.2 対象消防本部

調査対象は、政令指定都市を管轄する消防本部、東京消防庁、および各都道府県の代表消防本部で構成される52本部。全消防本部の悉皆調査ではなく、無作為抽出でもない。消防庁資料では2022年時点の消防本部数は723本部とされており、52本部の件数を単純に全国全体へ外挿してはならない。

したがって、集計値の正確な表現は「調査対象52消防本部の合計」であり、「全国全消防本部の実数」ではない。

### 2.3 調査報告の範囲

2020年4月23日通知は、原則週1回の報告を依頼している。消防庁の説明資料では調査実施期間を2020年4月27日からとしている。また、保健所等が医療機関への受入れ照会を行った事案は本調査に含まれない。消防機関による救急搬送の集計であり、感染症行政による移送や全医療機関の受入れ調整を網羅しない。

COVID疑い・非COVID疑いの内訳は、全体系列より短く、2021-03-29から2024-03-31までしか存在しない。2020年の流行初期をこの内訳で分析することはできない。

全体系列には正式調査開始日より前の4週（2020-03-30、04-06、04-13、04-20開始）にも数値が存在する。原本値は保持するが、収集経緯は公式資料から確認できていない。正式調査開始後のデータと同一の収集過程だったと仮定せず、主分析では除外し、必要なら感度分析に限定する。

## 4. COVID疑い／非COVID疑い区分の意味

消防庁の2023年説明資料では、COVID疑い事案は、37度以上の発熱・呼吸困難等のCOVID-19を疑う症状を認めた傷病者の事案と説明される。5類移行後は、保健所等が照会せず消防機関が照会したCOVID-19陽性者の事案も含むとされている。

このため、区分は検査確定に基づく感染状態の分類とは同一でない。「非コロナ疑い」は「COVID-19陰性が確認された患者」とは言えない。感染症状の有無や搬送調整の運用による分類であり、確定診断別の非COVID患者数として扱ってはならない。また、期間を通じた判定手順の完全な一貫性を示す詳細コードブックは今回確認できていない。

## 5. 2024年4月の調査方式変更

2024年4月4日付消防救第105号通知により、2024年4月8日から新様式が開始された。
- 救急搬送困難事案数の調査は継続
- COVID疑い事案数（内数）の調査は中止
- 救急出動件数を報告項目・公表図表に追加
- 月報告は終了し、週次報告を継続
- 2020年通知は廃止

本ExcelのCOVID疑い・非COVID疑い系列は2024年3月31日までで終了しており、新様式の開始前である。2024年4月8日以降にCOVID区分を補完・推計してはならない。全体系列は新様式移行後も継続するが、救急出動件数を分母にした割合を作成する場合は、対応する週次出動件数の原資料を別途新規取得・照合する必要がある。本Excel単独からは、全期間を通じた搬送困難率を計算できない。

## 6. 研究での使用可否

| 使用目的 | 判定 | 理由・条件 |
|---|---|---|
| 52消防本部における週次の救急受入れ調整困難の推移 | 使用可 | 対象・定義を明記し、原粒度の週次件数で記述 |
| 流行波・政策時期との時間的併存の記述 | 条件付き可 | 時間的併存に限る。因果効果と表現しない |
| 52本部内の消防本部別比較 | 条件付き可 | 管轄人口・救急需要・地域特性・報告範囲が異なるため、単純件数順位は避ける |
| 非COVID疑い区分の週次推移 | 条件付き可 | 2021-03-29〜2024-03-31のみ。確定陰性者群ではないことを明記 |
| 非COVID患者の搬送拒否・未搬送・治療拒否の件数 | 使用不可 | 調査項目が異なり、消防庁注記でも対象事案は搬送されている |
| 非COVID患者全体の医療アクセス格差・診療延期の直接測定 | 使用不可 | 外来・入院・手術・治療中断を測っていない |
| COVID-19陰性患者数の推計 | 使用不可 | 疑い区分は確定診断分類ではない |
| 全国全消防本部への単純外挿 | 使用不可 | 52本部の選定調査であり、悉皆・無作為標本ではない |
| 2024-04-08以降のCOVID疑い/非疑い比較 | 使用不可 | 内数調査が廃止された |

## 7. 推奨する研究上の位置づけ

データ表の領域は「非COVID医療アクセス」だけに限定せず、救急医療提供体制の負荷を示す背景指標として登録する。分析では以下を分離する。

1. **直接的な倫理問題の証拠**：非COVID患者の受診回避、診療延期、治療中断、疾患悪化等を扱うJACSIS等の患者調査や病院利用研究。
2. **救急医療の背景負荷**：消防庁の救急搬送困難事案数。
3. **感染症流行の背景**：新規陽性者・死亡者、入院・重症患者数等（定義と粒度を監査済みの系列）。
4. **制度・運用**：救急受入れ調整、病床確保、感染症患者移送体制等の通知・政策。

消防庁データの増加と非COVID患者のアクセス悪化が同時期に観察されても、それだけで一方が他方を引き起こしたとは結論づけない。患者調査・病院利用実績等の直接証拠と組み合わせ、地域・時間粒度が一致する範囲に限って関連を検討する。

## 8. 未解決事項・追加収集が必要なデータ

- 52消防本部の選定根拠・各本部の人口カバー率や救急需要カバー率の完全な定量評価。
- COVID疑い区分の時期別詳細な判定運用と変更履歴。
- 2024年4月以降の新様式による救急出動件数を含む週次原資料を、旧様式と区別して取得。
- 2020年4月27日以前の4週分の値の収集由来。
- 非COVID患者のアクセスを直接示す受診回避、外来・入院・手術延期、治療中断、服薬中断、疾患悪化の原資料。

これらが解消するまでは、救急搬送困難事案は「限定された52消防本部における救急受入れ調整困難の週次指標」としてのみ使用する。
