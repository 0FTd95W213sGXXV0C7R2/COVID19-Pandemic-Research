## 3. 定義変更・接続上の重要な注意

### 3.1 2021年と2022年
- 2021年資料は療養者数を入院・宿泊・自宅療養等・療養先調整中等に分ける。
- 2022年12月資料は臨時医療施設・入院待機施設を明示的に分け、確保病床/確保居室に位置付けられた者とそうでない者、入院先調整中などを追加的に区分する。
- 2022年資料の「療養者数」は注記に複数区分の加減算定義がある。単純な「入院者数＋宿泊療養者数＋自宅療養者数」と同一視しない。

### 3.2 2023年5月資料
- 2023-05-10時点の資料は、入院者数、宿泊療養者数、社会福祉施設等療養者数、病床・宿泊施設のフェーズ/即応数/確保数を併記する。
- 公表ページのPDFは2023-09-06修正の注記を含む。公表時点の初版と後日修正版を同一ファイルとして扱わず、修正履歴を残す。
- 2023-05資料の病床使用率は確保病床数を分母とする注記があるが、重症者用病床の列やフェーズの対応も含めて列単位で識別する必要がある。

### 3.3 2023年10月資料
- 2023-10-25資料の注記には、2023年9月15日付事務連絡に基づく10月以降の確保病床計画について、一部都道府県で調整中の数値があると記載される。
- 10月1日〜31日の経過措置として、段階1未満の感染状況でも段階1に対応する即応病床数等が表記される場合がある。原表の「現段階／最終段階」と数値欄を独立に読む必要がある。
- 調整中の都道府県・項目は「－」で表示されることがあり、ゼロとみなさない。
- したがって、2023年10月は単純な定義変更点ではなく、病床計画・経過措置の移行期として扱う。

### 3.4 2024年3月最終資料
- 一般・中等症II・重症の病床使用率は確保病床数が分母であり、即応病床数ではない。
- 2024年最終資料では宿泊療養・自宅療養・療養先調整中等の系列は主要表に確認できず、2021/2022年の療養者総数と接続しない。
- 社会福祉施設等療養者数は、入院者数とは別の把握項目である。入院者数に加算しない。

## 4. 時系列分析の採用方針（暫定）

1. **全期間共通系列として無条件に接続できると確認された指標は、現段階ではない。**
2. 入院者数・確保病床内入院者数・一般病床確保数・重症者数等は候補だが、各報告時点の定義・対象範囲・欠測表記・修正履歴を追加確認してから接続する。
3. 宿泊療養、自宅療養、療養先調整中、臨時医療施設関連は、2021/2022年の多項目構造と2023/2024年の縮約された主要表を連結しない。
4. 2023年5月8日の感染症法上の位置付け変更、2023年10月の病床計画移行期、2024年3月の調査終了を、データ系列の注記・層別化候補として保持する。これらを単独でデータ定義変更の証拠とはしない。
5. 2023年5月資料の2023-09-06修正、2022年12月資料の2023-01-20修正、2021年10月資料の2021-11-17修正を必ず監査台帳に記録する。
6. 今回は代表時点の定義比較であり、週次全件のデータ再構築や全期間の列対応確定は未完了。
