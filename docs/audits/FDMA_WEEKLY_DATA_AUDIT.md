## 3. 定義・対象範囲

消防庁資料の定義は、救急隊による「医療機関への受入れ照会回数4回以上」かつ「現場滞在時間30分以上」の事案。対象は政令市消防本部・東京消防庁及び各都道府県の代表消防本部、計52本部と説明されている。

重要な解釈上の制約：
- 「救急搬送困難事案」は、受入れ先決定に困難・遅延が生じた事案の指標である。
- 消防庁資料は、これらの事案のうち医療機関へ搬送できなかった事案はないと明記している。
- したがって、搬送拒否、未搬送、治療拒否、非COVID患者の受療不能を直接測る指標として扱わない。
- 調査対象は全国の全消防本部ではなく52本部であり、地域の救急搬送状況を完全に網羅する悉皆統計ではない。
- 保健所等が医療機関へ受入照会した事案は調査対象外とされる。

## 4. COVID疑い／非COVIDの区分

変換スクリプト `make.js` は、Excelの先頭シートを読み込み、列見出し `救急搬送困難事案　今回` を確認してから、消防本部別の週次値を抽出している。生成される3種類のCSVの列には、COVID疑い／非COVIDの区分が存在しない。

よって、今回監査したCSVは総数系列としてのみ使用可能であり、COVID疑い事案とそれ以外を分離する用途には使用できない。元Excelの別シート・別系列に区分データが存在するかは、公式Excelの全ワークシートを直接解析できていないため未確定。研究でこの区分が必要な場合、元Excelのシート構造を別途確認する。

## 5. 時系列上の制約

この変換データの最終週は2023-05-07までである。2023-05-08の感染症法上の5類移行後を含む連続系列として扱わない。消防庁ページには後年の調査資料も掲載されているが、調査様式・集計項目・対象本部・比較方法の同一性を確認するまでは、このCSVと接続しない。

## 6. 研究上の採用判断

**条件付き採用。**

採用用途：
- 流行期に救急搬送の受入調整が困難になった時期・規模を示す背景指標。
- 週次の疫学指標・医療提供状況との時間的併存や関連の探索。
- 可能な範囲で都道府県別の地域差を記述する補助指標。

禁止・回避する解釈：
- 搬送困難件数を、搬送拒否件数・未搬送件数・治療拒否件数と読み替えない。
- COVID疑い以外の患者だけの件数と読み替えない。
- 週次値を日次値へ補間しない。
- 52本部の集計を全国全消防本部の悉皆データと表現しない。
- 2023-05-08以降の別様式の調査結果と、定義監査なしに連結しない。
- 流行指標との同時変動だけから、COVID流行が搬送困難を引き起こしたと因果断定しない。

データ辞書には、粒度＝週次、対象＝52消防本部、地理単位＝全国／都道府県／消防本部、定義＝受入照会4回以上かつ現場滞在30分以上、欠測＝2022-03-07週の秋田県1行、期間＝2020-03-30～2023-05-07、限界＝搬送拒否を意味しない・COVID区分なし、を記録する。
