# 希少資源配分研究：医療負荷データ・政策イベントの対応監査

作成日時：2026-11-26 JST

## 1. 目的と判定

希少資源配分に関する3研究（Norisue 2021、Ishizaki 2023、Mori 2026）の対象期間に対し、厚生労働省等が公開する医療負荷・病床状況資料と、医療提供体制の制度変更時点を対応付ける。ここでの作業は出典発見・公開範囲確認・分析可能性の監査であり、全国値から個別施設の逼迫度や倫理問題の発生を推定するものではない。

**結論：** 2020年4月28日から2024年3月27日までの都道府県別「療養状況等及び入院患者受入病床数等」週次公表資料が確認でき、対象研究期間の背景データ候補として最も有用である。2020年8月から2023年5月には別系統の「医療提供体制等の状況（6指標）」の週次スナップショットも公開されている。さらにG-MISの週当たり新規入院患者数とICU・ECMO/人工呼吸器管理患者数は2022年12月5日以降の系列が確認できる。これらは別の調査・集計体系であり、同一系列として接続してはならない。

今回、公式ページ・公表PDFの存在と定義・期間を確認した。XLS/XLSXの一括ダウンロード・列構造監査・全件再構築は未実施である。従って取得状態は「出典発見・公開メタデータ確認」であり、「原資料取得」「データ抽出」「品質監査」ではない。

## 2. 公的データソースの区分

### 2.1 療養状況等及び入院患者受入病床数等（厚生労働省）

公式ページ：
https://www.mhlw.go.jp/stf/seisakunitsuite/newpage_00023.html

公開期間の確認：
- 最古の掲載資料：2020年4月28日0時時点（2020年4月28日・5月1日等の初期資料を含む）。
- 最新の掲載資料：2024年3月27日0時時点。
- 厚生労働省は2024年3月27日0時時点分の公表をもって本調査を終了したと明記。
- 多くの期間で週次スナップショットとPDF/XLSを掲載。初期資料の一部はPDFのみである可能性があるため、各リンクの実体を個別確認する。

2024年3月27日資料で確認できる主な項目：
- 在院者数
- 確保病床に入院している者数／確保病床外に入院している者数
- 病床確保計画上の現段階／最終段階
- 即応病床数、確保病床数、確保病床使用率
- 中等症II患者数と、その確保病床内外の内訳
- 重症者数と、その確保病床内外の内訳
- 中等症II・重症者用の即応病床数、確保病床数、確保病床使用率
- 高齢者・障害者施設等での療養者数（都道府県が把握した範囲）

2024年3月27日資料の定義：
- 即応病床数：当該段階で準備病床からの切替が完了し、要請があれば即時受入可能または既に受入中の病床数。
- 確保病床数：いずれかの段階で患者受入れを行うことについて医療機関と調整済みの病床数。
- 確保病床使用率：確保病床数に対する、確保病床に入院している患者数の割合。

**分析上の扱い：**
- 「在院者数」「確保病床に入院中」「即応病床」「確保病床」は異なる量として保持する。
- 確保病床使用率の分母は即応病床数ではなく確保病床数。異なる分母で再計算しない。
- 病床段階（段階1〜3）と病床確保計画の改訂を保持する。
- 2023年5月8日の5類移行後も同じ調査が2024年3月まで継続しているが、制度・受入れ体制の移行期間中の測定である。2023年5月8日を跨ぐ単一の同質系列とは無条件に扱わない。
- 2023年夏の資料では週次公表が続いていることを確認。アーカイブの全週欠落・差替履歴は未監査。

### 2.2 都道府県の医療提供体制等の状況（6指標）

公式ページ：
https://www.mhlw.go.jp/stf/seisakunitsuite/newpage_00035.html

公開範囲：
- 最古の掲載資料：2020年8月14日更新。
- 最新の掲載資料：2023年5月9日更新。
- 2020年9月以降、PDFとXLSの両方が掲載されるスナップショットが多数確認できる。
- 2021年以降にファイル差替え表示がある資料が複数ある。原版と差替版を区別し、最終版を取得する場合も更新履歴を残す。

2020年10月時点の公表PDFから確認できる項目例：
- 新規陽性者数（直近1週間・人口10万人対）
- 直近1週間とその前1週間の新規陽性者数比
- 確保病床使用率
- 重症患者の確保病床使用率
- 療養者数（人口10万人対）
- 入院率
- 自宅療養者数・療養等調整中の数
- 陽性者数・検査件数比（検査件数の範囲に注意）

資料タイトルの「6指標」とPDF内の表記・集計項目が完全に一対一対応するか、また時期により追加項目があるかは、各時点のExcel/PDFで列・定義を確認して確定する。2020年10月PDFでは陽性者数・検査件数比が一般的な陽性率とは異なる旨の注記がある。これを通常の検査陽性率と同一視しない。

**分析上の扱い：**
- 6指標の各項目は時点別・都道府県別のスナップショットとして管理。
- 指標定義・分母・データソース・差替え履歴が確認できる期間のみ比較する。
- 療養状況等の病床調査と同じ病床使用率という名称でも、計算定義・観測時点が一致するとは限らない。列定義を照合してから比較する。
- 2023年5月9日以降に同じ様式が継続しているとは確認できない。5月8日以降のデータに延長しない。

### 2.3 G-MIS週次報告：新規入院・ICU・ECMO/人工呼吸器

公式参考ページ：
https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000121431_00130.html

確認できた公開資料：
- 2022年12月5日を始点とする週当たり新規入院患者数の推移。
- 週当たり新規入院患者数（合計値）。
- ICU入院中患者数（7日間平均）。
- ECMOまたは人工呼吸器管理中患者数（7日間平均）。
- ICUの定義は、特定集中治療室管理料または救命救急入院料を算定している病床。
- G-MIS入力値を用いた速報値で、報告遅延・修正があり得る。直近2週間は前週公表値も含め更新される場合がある。
- 厚労省の国内発生状況ページは、2023年5月8日の5類移行に伴う公表内容の変更に加え、2023年10月から新規入院者数等の公表内容も変更したと明記。

確認済みの例：
- 2023年第27週（7月3日〜7月9日）：新規入院患者数6,320（別時点の速報資料では6,096に改訂）、ICU 7日間平均91（別資料では87）、ECMOまたは人工呼吸器管理7日間平均51（別資料では50）。同一報告週でも公表時点によって改訂されることを確認。
- 2023年第34週（8月21日〜8月27日）：新規入院13,501〜13,972、ICU 218〜228、ECMOまたは人工呼吸器136〜140の範囲で、資料の公表時点により差がある。

**分析上の扱い：**
- 報告週・公表日時・取得時点を必ず保持し、同じ週の改訂値を上書きで消さず、スナップショットとして管理する。
- 新規入院患者数（週合計）とICU/ECMO/MV管理患者数（7日間平均）を混同しない。
- 「ECMOまたは人工呼吸器」は合算・複合指標であり、ECMO単独値または人工呼吸器単独値として扱わない。
- 公表ページ上、2022年12月5日より前の同じ定義による連続系列は確認できていない。
- 2023年10月の公表方式変更前後を一つの同質系列とみなさない。

### 2.4 CRISIS／日本ECMOnet

公式ページ：
https://www.ecmonet.jp/crisis

- CRISISは2020年2月中旬に立ち上げられたCOVID-19重症患者データベース。
- 2020年7月10日時点で610超施設、約5,500 ICUベッド、日本のICUベッド約6,500床の約80%をカバーすると日本ECMOnetが説明。
- 厚労省2022年6月15日会議資料は、2020年2月9日〜2022年6月12日の累積ECMO装着患者1,287人、軽快離脱814人、死亡466人、継続7人を掲載。
- CRISIS公開データへのリンクは確認できたが、今回の確認では公開画面から再利用可能な日次/週次CSVの直接取得方法・列定義・改訂履歴は確定していない。

**分析上の扱い：**
- 2022年6月12日までの累積症例数は、累積の患者実績であり、各時点の稼働中患者数・病床占有率とは別物。
- 施設カバー率の説明は2020年7月10日時点の説明であり、全期間の一定カバー率とみなさない。
- 研究論文に掲載された集計値を日次系列に変換しない。
- 公開画面からの原資料取得・列定義・履歴監査が完了するまで、CRISIS日次系列は未取得とする。

## 5. 3研究への暫定的な接続判断

### Norisue
- 調査時点の正確な日付を原著の方法・補足資料から確定する。
- その日付に最も近い病床状況週次スナップショットと6指標を使用候補とする。
- 個人回答と全国・都道府県負荷を個人レベルで結合しない。地域が一致しない場合は全国背景の記述に限定する。

### Ishizaki
- 面接日（2022年2〜4月）と、回答者が語った経験の発生時期を分ける。
- 経験時期が特定できる場合だけ該当週の病床・感染状況と併記する。
- 面接対象施設の所在地・病床数・当該時点の実際の逼迫度が確認できない場合、全国値は参考背景にとどめる。

### Mori
- 回顧期間（2020年1月〜2023年5月）を一括の単一条件とみなさず、調査票の時期区分・項目別対象期間があれば分ける。
- 2020年〜2023年5月の病床調査・6指標を背景にできるが、回答施設の実測逼迫度ではない。
- 2022年12月以降のG-MISを補助利用する場合も、全国集計の別系列として扱い、27施設に割り当てない。
- 本文・補足データのQ2a/Q7a/Q7b不一致は、背景負荷データで解消しない。

## 6. データ取得・分析前の必須監査

1. 療養状況等調査：全掲載時点の一覧を機械取得し、欠落週・重複時点・PDF/XLS有無・差替履歴を一覧化。
2. 各時点のXLSを取得し、シート・列・定義・単位・都道府県・欠損・「－」等の表記を監査。
3. 2020年初期資料と2024年最終資料で列定義の変更を比較。
4. 6指標：全ファイルの掲載日、差替表示、列名、分母、算定方法、参照データを監査。
5. G-MIS：各週の公表PDFをスナップショットとして収集し、報告週・公表日時・改訂値を保存。2023年10月の公表変更前後の定義を確認。
6. CRISIS：公開画面のデータ形式・対象期間・列定義・利用条件を確認。取得できない場合は論文・行政資料の集計値に限定。
7. 感染者数等の疫学系列、政策イベント、医療負荷指標は、出典・定義・時点が一致する場合のみ時系列照合する。
8. 研究対象の調査・経験時点が特定できない場合、関連分析ではなく記述的な背景説明に限定する。

## 9. 2026-11-26 JST 追補：病床状況調査アーカイブのファイル実体確認

### 9.1 掲載形式の確認
