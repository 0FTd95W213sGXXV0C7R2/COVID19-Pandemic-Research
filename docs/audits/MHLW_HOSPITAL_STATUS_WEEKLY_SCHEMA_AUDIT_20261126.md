## 2. 週次で維持されていることを確認した表構造

取得できた23件のPDFのテキスト層を比較した範囲では、2023-10-25以降の基本的な表構造は維持されている。

- (1)①-1 在院者数
- (1)①-2 うち確保病床に入院している者数
- (1)①-3 うち確保病床外に入院している者数
- (1)②-1 うち中等症II患者数
- (1)②-2 うち確保病床に入院している中等症II患者数
- (1)②-3 うち確保病床外に入院している中等症II患者数
- (1)③-1 うち重症者数
- (1)③-2 うち確保病床に入院している重症者数
- (1)③-3 うち確保病床外に入院している重症者数
- 一般・中等症II・重症それぞれの病床について、現段階/最終段階、即応病床数、確保病床数、確保病床使用率
- (2) 社会福祉施設等療養者数

注4は、確保病床使用率を確保病床数に対する当該区分の確保病床内入院者数の割合として定義している。即応病床数を分母にする定義ではない。即応病床数は現在の段階で準備病床から切替済みで即時受入可能または既に受入中の病床、確保病床数は段階を問わず受入要請に対応することを医療機関と調整済みの病床であり、両者は別変数である。

この結論は、取得できたPDFの見出し・注記の比較に基づく。取得不能3件は未確認であり、26件すべての完全な同一性を証明したものではない。

## 4. 重要な異常・データ取扱い

### 4.1 2023-12-06報告の「－」と合計行の0

2023-12-06 PDFでは、47都道府県の行で、確保病床内外の入院者数および各病床容量・使用率の多数の項目が「－」で表示される。一方、合計行では該当する複数列が数値の0として表示される（例：合計行は在院者数6,246、社会福祉施設等療養者数0、続く複数の確保病床内外・病床数列が0、中等症II患者数905、重症者数65等）。
- 都道府県行の「－」は数値0として転記しない。
- 合計行の0は、都道府県行に数値がなく「－」である列について、実際の患者数・病床数が0であったことの証明にはならない。
- 「－」の定義は当該PDF注記からは確定できないため、意味を推測せず原表記を保持する。
- 2023-12-06の当該列は欠測/非数値として扱い、0として時系列分析に投入しない。Excel原票との照合と厚労省側の定義確認が必要。

### 4.2 2024-02-02アーカイブ表示とPDF本文の不一致

アーカイブは「2024年2月2日0時時点」と表示する一方、リンク先PDFの本文タイトルは「2月7日0時時点」、公表日は2月9日と記載する。今回確認できた公式資料間の不一致であり、理由は不明。
- アーカイブ表示日とPDF本文日を別々に保持する。
- データの日付を推測で2/2または2/7に統一しない。
- Excel版、アーカイブ更新履歴、厚労省への照会等で解決するまで、週次系列の正式日付は要確認フラグを付ける。

## 5. 暫定判定

1. 取得できた23/26件では、表の基本的な項目構成・病床使用率の分母定義に明確な変更は見つからなかった。
2. よって2023-10〜2024-03の同一カテゴリ内系列は、週次接続の候補として前進させる。
3. ただし、取得不能3件、2023-12-06の非数値列、2024-02-02/2-7の日付不一致、修正履歴、XLSX原票との未照合が残るため、現時点で完全な週次データセットを確定・分析に投入しない。
4. 2023-12-06の「－」は欠測/非数値のまま保持する。合計行の0で補完しない。
5. 2024-02-02アーカイブ表示とPDF本文の日付を分けて保存する。
6. 「一般」「中等症II」「重症」は別カテゴリのまま保持し、過去時点の分類に統合しない。
