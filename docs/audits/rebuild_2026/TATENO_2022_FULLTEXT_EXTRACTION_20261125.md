# 立野ら（2022）全文抽出記録：救急・集中治療領域の終末期面会

## 1. 研究目的・デザイン

救急・集中治療領域におけるCOVID-19終末期患者の家族面会・死亡宣告時の家族立ち会いの実態、および救急・集中治療看護師と感染管理者の面会に対する意識を明らかにする横断的Web質問紙調査。

- データ収集期間：2021年6月25日～7月30日。
- 対象：救急初療・ICU等、COVID-19重症患者を受け入れる部署の看護師、およびCOVID-19患者受入施設の感染管理を担う看護師。
- 回答：救急・集中治療領域の看護師181名、感染管理者94名。
- 有効回答：救急・集中治療領域180名、感染管理者94名。
- 施設実態分析：施設重複を調整し、救急・集中治療看護師180名から109施設を分析。各施設から1名を無作為抽出して施設実態を分析。意識調査は回答者全員を分析。
- 調査：独自作成の2種類のWeb質問票、選択式と自由記述。質問項目は救急・集中治療看護の専門家5名、感染管理の専門家1名が妥当性・表現等を検討。
- 分析：質問項目ごとの記述統計。自由記述は内容の類似性に基づいて分類・整理。
- 倫理審査：日本クリティカルケア看護学会・日本救急看護学会の倫理審査委員会、承認番号「日本クリティカルケア看護学会2021-1」「日本救急看護学会021号」。

## 2. 施設における面会実施状況

### 終末期患者への家族面会（109施設）

- 実施している：40施設（36.7%）
- 実施する場合としない場合がある：42施設（38.5%）
- 実施していない：27施設（24.8%）

面会方法（n=82の方法回答）：
- 窓越し面会：24施設（29.3%）
- 状況に応じた方法選択：24施設（29.3%）
- リモート面会：19施設（23.2%）
- PPE装着でのベッドサイド面会：13施設（15.9%）
- その他：2施設（2.4%）

面会時間は短時間制限が68施設（82.9%）。面会人数は少人数制限が47施設（57.3%）。頻度は1日1回36施設（43.9%）、制限なし18施設（22.0%）、1日数回7施設（8.5%）。

### 死亡宣告時の家族立ち会い（109施設）

- 実施している：28施設（25.7%）
- 実施する場合としない場合がある：39施設（35.8%）
- 実施していない：42施設（38.5%）

立ち会い方法（n=67の方法回答）：
- PPE装着でベッドサイド：20施設（29.9%）
- 窓越し：19施設（28.4%）
- 状況に応じた選択：14施設（20.9%）
- リモート：12施設（17.9%）
- その他：2施設（2.9%）

### 院内基準

感染管理者回答では、終末期家族面会の基準を「すべてまたは一部定めている」79/93（84.9%）、「あまりまたは全く定めていない」14/93（15.1%）。死亡宣告時の立ち会い基準は60/93（64.6%）が定め、33/93（35.4%）が未整備またはほぼ未整備と回答。

## 3. 看護師・感染管理者の意識

### 救急・集中治療領域の看護師

- 終末期の家族面会を行うべき：162/179（90.5%）
- 行うべきではない：17/179（9.5%）
- 死亡宣告時の家族立ち会いを行うべき：162/178（91.0%）
- 行うべきではない：16/178（9.0%）
- 家族面会が感染リスクを高めると思う：70/179（39.1%）
- 高めるとは思わない：109/179（60.9%）

### 感染管理者

- 終末期の家族面会を行うべき：81/93（87.1%）
- 行うべきではない：12/93（12.9%）
- 死亡宣告時の家族立ち会いを行うべき：75/93（80.7%）
- 行うべきではない：18/93（19.3%）
- 家族面会が感染リスクを高めると思う：35/93（37.6%）
- 高めるとは思わない：58/93（62.4%）

※「行うべき」という意識は実施率や介入効果ではない。感染リスクの回答も実測感染率ではなく回答者の認識である。

## 4. 自由記述から得られた理由・論点

面会を支持する理由：
- 家族が患者の状況を受け止めるため
- 家族への悲嘆ケア、複雑性悲嘆のリスク軽減への期待
- 患者・家族の希望を尊重するため
- 家族にも会う権利があるという認識
- 最期の時間を共に過ごしてほしいという医療者の思い
- PPE等の工夫により面会環境を整えられるという考え

慎重・反対理由：
- 二次感染リスクへの懸念
- 家族が涙を拭う際に目・鼻・口に触れる可能性
- 面会支援に必要な看護師のマンパワー不足
- 看護師の業務負担
- 家族自身の心理的負担への懸念

## 5. 著者の考察・提案

- 一律禁止ではなく、院内へのウイルス持ち込みリスクと患者から家族、家族から医療者への伝播リスクを分けて評価する。
- 地域流行状況、家族のワクチン接種状況、曝露歴、健康状態などを踏まえ、リスクの有無だけでなく程度と低減可能性を考慮する。
- 適切なPPE着用指導、空気感染予防策、面会中の支援体制を準備する。
- 窓越し・リモート面会は接触機会を作る一方、重症患者の状態理解や直接接触の代替として不十分な場合がある。
- 終末期・死亡宣告時の面会基準を施設ごとに明確化し、組織的に検討しておく。

これらは著者の提案・考察であり、当該調査が感染低減や悲嘆軽減の効果を検証したものではない。

## 6. 研究の限界

著者が明記した限界：
- 救急・集中治療看護領域の学術団体会員と感染症指定病院の感染管理者を対象としており、非会員施設や感染症指定病院以外の情報を含まない。
- 国内の全施設・全患者における実態や看護師意識を代表するものではない。

追加の解釈上の注意：
- 施設実態分析は109施設で、回答者総数275名とは分母が異なる。
- 項目ごとに分母が異なる。特に方法・頻度・態度項目の分母を混同しない。
- 横断的な自己記入式調査であり、回答バイアスや選択バイアスの可能性がある。
- 家族・患者本人への調査ではなく、看護師・感染管理者の回答である。
- 感染の実測値、家族の悲嘆の実測値、面会による因果効果は測定していない。
- 抄録と本文の記述に、面会実施施設数の表現に不整合がある。本文図1・結論では「実施している」40/109（36.7%）。抄録の24施設（29.3%）は図2の窓越し面会方法24/82（29.3%）と一致する。本文の表・図に基づき、実施率は36.7%を採用し、抄録の24/29.3%は方法項目の数値との混同可能性として監査事項に残す。
- Abstract states responses of 181 and 94; results specify valid responses 180 and 94. Item-specific denominator 179/178 must be preserved.

## 8. 研究目的との対応

- 自律・尊厳：終末期の家族面会、死亡宣告時の立ち会い、家族の権利・希望。
- 家族への心理的影響：死の受容、悲嘆ケア、複雑性悲嘆リスクへの懸念。ただし家族本人のアウトカムを測定していない。
- 医療従事者の負担と互恵性：感染管理者が指摘した人員不足・看護師負担。
- 感染対策との比例性：一律禁止ではなく、リスク評価・低減策を踏まえた個別判断の提案。
