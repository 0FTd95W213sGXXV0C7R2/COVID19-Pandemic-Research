## 原資料と独立照合

消防庁から取得した現行Excel（286,999バイト）のSHA-256はリポジトリの保存版と一致した。今回の取得は二つの公式掲載ページ、通知、調査説明、年次資料、週報を含め**96件**。URL、取得時刻、HTTP、形式、容量、SHA-256を残し、取得バイナリは作業領域に保存した。96件中、数値表を照合した週報は88件。公式掲載ページで、Excel終端後の週報が別ページで公開されることを確認した。[消防庁のExcel掲載ページ](https://www.fdma.go.jp/disaster/coronavirus/post-1.html) [後続週報](https://www.fdma.go.jp/disaster/coronavirus-situ/post-1.html)

Excel内部XMLを直接読み、元の変換スクリプトに依存せず、**44,308行すべてで差異0件**。原セル値・合計の数式、週開始・週末日・前年同期の対応、消防本部、都道府県結合セルを照合した。52消防本部の名称・順序は4シートで一致し、47都道府県に属する。観測単位は原表の消防本部と52本部合計。都道府県名は所在地・管轄の手がかりであり、選定本部の値を各都道府県全体に外挿できない。

## 定義、集計範囲、再監査箇所

救急隊の受入れ照会が4回以上、かつ現場滞在が30分以上の事案を数える。保健所等が受入照会を行ったものは除外。政令市、東京消防庁、各都道府県の代表を含む52本部の選定調査である。コロナ疑いは発熱37度以上・呼吸困難等の報告上の分類で、2023年5月8日の5類移行後には、保健所等が照会せず消防機関が照会した陽性者も含む。非疑いは陰性確認済みの集団と区別し、移行前後に別の定義IDを付けた。2024年4月8日から新様式となり、疑い内数と月報を終了し、週報に救急出動件数を追加した。疑い別Excelの最終週は3月25〜31日。全体の旧・新様式も定義IDを分けた。[調査説明資料](https://www.fdma.go.jp/singi_kento/kento/items/r5-1/01/shiryou2-2.pdf) [消防救第105号](https://www.fdma.go.jp/disaster/coronavirus-situ/items/240408_kyuuki_01.pdf)

- Excelの消防本部合算と全国欄は**835列で完全一致**。2022年3月7〜13日は秋田市消防本部の全体が空欄。疑い・非疑い欄は両方が報告ゼロだった。51本部の既知値の和は公表合計と一致したが、52本部の照合としては保留。秋田市と52本部合計を各系列の主分析から外し、他の51本部の観測は維持した。公表区分の算術は8,320組で一致（本部8,163組、合計157組）、秋田市の1組は不完全。前週の秋田市は全体・疑い・非疑いがすべて0、翌週は順に1・0・1。該当週の原表空欄の理由・訂正は確認できなかった。
- 2024年4月1日週はExcel見出しに「4/8(日)」とあるが、公式週報は4月1〜7日と記載し、52本部と合計の53値がExcelと一致した。新しい集計表では4月7日を使用し、印字日4月8日と根拠を保持した。前年同期の2022-06-27、07-04開始週の曜日括弧欠落は日付の変更を伴わない書式差。原表の報告ゼロ8,601セル、空欄1セル、件数欄の非数値0セルを区別した。[4月1〜7日週報](https://www.fdma.go.jp/disaster/coronavirus-situ/items/coronavirus_kekka.pdf)
- Excel内で本部名の交代は確認されなかった。後続週報では名目52本部のうち、東京消防庁のシステム改修による集計除外（2026年2月1日〜5月3日）、仙台市消防局のシステムエラー（4月13日週）、千葉市消防局の改修（5月11〜31日、11月16日以降）など、実際の報告範囲の変化や後日のデータ反映を確認した。週報ごとに本文注記・抽出対象本部・両指標の照合結果を保存し、52本部がそろわない版は率の採用を保留した。[東京・仙台の除外注記](https://www.fdma.go.jp/disaster/coronavirus-situ/items/r8/coronavirus_kekka_r80413.pdf) [千葉の除外注記](https://www.fdma.go.jp/disaster/coronavirus-situ/items/coronavirus_kekka_r81116.pdf)
- 今回欄と後続版の前週欄の比較では、2025年3月24日週の救急出動が京都市で1,930→1,929件、52本部合計で64,497→64,496件となった。版・URLを記録し、採用CSVでは当該週の公表版を保持した。全国行と本部値が一致しない2025年9月8日週・2026年11月9日週も保留。両週はPopplerとPyMuPDFが同じ行を読み取った。9月8日週は件数1,753対1,752、11月9日週は件数1,698対1,710・出動71,696対71,605。差の理由と正式訂正は未確認。6月8日週の鳥取は、別の読み取り方式で折り返し行を復元し、両指標の合計を確認できたため採用した。[3月24日週報](https://www.fdma.go.jp/disaster/coronavirus/items/coronavirus_kekka.pdf) [後続版](https://www.fdma.go.jp/disaster/coronavirus-situ/items/r7/coronavirus_kekka_r70331.pdf)

## 分母と採用範囲

週報の**今回欄に並ぶ救急出動件数と搬送困難事案数**を使い、同じ印字期間・本部集合・公表版で、両指標の52本部合算が公表合計に一致する場合だけ、100出動当たり件数を算出した。88週報のうち**67週、3,551行**（本部別52行＋合計1行／週）を採用し、21週は報告範囲、表抽出、または合計照合を理由に保留した。対象は2024年4月1日週、2025年3月24日週、2025年3月31日以降の通過週。欠落週の値は補わない。一例として2024年4月1日週は2,680件／60,603出動で、100出動当たり4.422223件。各本部、合計、出典、版を保持した。Excel全期間の連続した分母、疑い別分母、同じ週・本部範囲の搬送実施件数は確認できなかった。[週報の分母付き原表](https://www.fdma.go.jp/disaster/coronavirus-situ/items/coronavirus_kekka.pdf)

消防庁「令和7年版 救急・救助の現況」は令和6年暦年の全国救急出動771万8,380件と搬送人員676万9,172人を収録する。週次・選定52本部とは期間・地域が異なり、搬送人員は単位も異なるため今回の分母に採用しない。年次全国値を52本部や週に配分しない。[令和7年版 救急・救助の現況](https://www.fdma.go.jp/publication/rescue/items/kkkg_r07_01_kyukyu.pdf)

## 倫理研究での利用

採用するのは、救急受入れ調整に負荷がかかった時期・地域の背景、疑い分類間の報告上の差、整合する一部週の出動当たりの負荷。死亡、治療遅延、搬送拒否、未治療の発生や因果効果の評価には、患者転帰などの別資料が必要である。比較時は対象消防本部と定義期間を明示し、COVID-19確定例と非COVID-19確定例の比較として解釈しない。

## 成果物と再現

`data/audits/fdma/emergency_transport/final_20261126/` に原資料マニフェスト、変数定義、品質フラグ、全国照合、週報の採否、改訂照合、分析用の件数・出動当たり指標CSV、採用判定、検証結果を保存した。再現にはPython、PyMuPDFとPopplerの `pdftotext` を使用する。以下の作業領域には取得原本を保存した。

```bash
python scripts/audit_fdma_final.py --private-dir /workspace/work/fdma-final-archive
python scripts/audit_fdma_final.py --private-dir /workspace/work/fdma-final-archive --reuse-downloads
```

現在の公開週報は後日追加され得る。今回と同じ範囲を再現する場合は、`--reuse-downloads` で保存版をマニフェストのSHA-256と照合して再処理する。
