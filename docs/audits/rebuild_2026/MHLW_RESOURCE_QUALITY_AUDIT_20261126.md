# 厚生労働省の医療資源配分データ品質監査

## 対象と結果

作業日時（日本時間）は末尾の実行記録を参照。

対象はリポジトリに保存済みの「療養状況等及び入院患者受入病床数等に関する調査結果」と G-MIS 医療機関別公表資料。既存の取得台帳、監査 JSON、見出しレビュー、代表週の一次資料注記を参照した。今回の確認範囲は保存済み原資料で、公式サイトからの再取得や初版との比較は行っていない。

- 週次調査 Excel は513パス、171種類。全ファイルのサイズと SHA-256 を測定し、重複342パスは代表ファイルとバイト単位で照合した。既存台帳に掲載された代表パスを優先した。
- G-MIS は43ファイル、43種類。既存の3種類の見出し、報告状況、施設数、実績日、数値欄の監査結果を再現した。施設データの実績日は2021-12-01〜2024-03-06の間に不定期で存在する。施設の入れ替わり、未報告または過去入力値の表示、施設コード欠損があるため、週次調査への結合や都道府県連続系列への変換は保留した。
- 週次調査171シートを読み、9種類の列構造と100種類の旧候補見出しについて、件数および日付別の値プロファイルを再現した。原注記のセル番地と出現箇所を独立に保存し、既存の注記テキストをすべて再現した。
- 本文基準日で2020-12-23〜2024-03-27の171週、各週47都道府県。分析準備用の縦持ちCSVは211,124行。値、型、表示書式、原セル位置を保持し、列ごと・報告日ごとの識別子でクロスウォークと連結できる。使用率は原表値を保持する。Excelの割合表示や数値に付く百分号は `number_format` と合わせて解釈する。
- 既存取得台帳の2024-02-02は、Excelの `C1` と `S1` により基準日2024-02-07・公表日2024-02-09と確認した。台帳の日付は比較列に保持した。これにより保存済み171週の調査間隔は全170区間で7日となる。公式アーカイブ側の表示差異の原因は残る。
- 全国値は原表の「合計」行を認識した。2026-11-19比較監査文書には全国行なしと記載されているが、例えば最終週では `A56` に「合計」がある。加算対象の床・室・人について、全47都道府県と全国値が数値の場合に照合した。使用率・フェーズなどは除外した。
- 原表の「－」15,098セルを保存した。数値として記載されたゼロ49,925セルには `reported_zero` を付け、実態としてのゼロかは別途確認が必要。2023-12-06報告には全国値0でも全都道府県がダッシュの列がある。地域行が不足する集計では部分和を全国値と比較しない。

## 再現方法と残る確認

Python 3.12と openpyxl 3.1.5 で実行した。リポジトリ直下で次を実行すると、この監査の出力を再生成する。

```bash
PYTHONDONTWRITEBYTECODE=1 python scripts/rebuild_mhlw_resource_quality.py
```

原資料は読み取り専用で処理する。ブックまたはCSV単位の処理エラーは `validation.json` の `errors` と品質フラグに残る。修正後は同じコマンドで全出力を再生成できる。openpyxl は一部の条件付き書式拡張を読み込まない旨の警告を出した。Excelの表示色による段階判定は行わず、原表の値と注記を使った。

次工程は、PDFのみの初期期間、修正前の版、列定義の未確定箇所、自治体別の地域基準と推計・報告上のゼロの適用先を一次資料で追加照合する。分析への採用は区分と分子・分母が同じと確認できる期間ごとに進める。
