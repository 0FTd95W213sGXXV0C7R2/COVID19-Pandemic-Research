## 採用判定と連続期間

全171週について各列の分母を47とし、数値の取得率、ダッシュと空欄を合わせた欠損率、注記付き値等の非数値件数、定義判定を記録した。集約表では定義判定の確定数を列出現数で割り、調査票に当該列が掲載されない週は別欄にした。連続期間は同じ定義群内で、確定済みかつ47都道府県で数値がそろう週が7日間隔で続く範囲。数値0は原表の数値として率に含めた。使用率の再計算は行っていない。

同一期間内の記述分析に採用可68群、数値のある都道府県に限る条件付き22群、保留31群。例として、2021-06-02〜2021-12-15の確保病床内入院者・確保病床数、2021-12-22〜2023-05-03の即応病床・確保病床・確保病床に位置付けられた臨時施設の内訳、2023-05-10〜2023-09-27の確保病床内外の入院者がある。2023-10-04以降の一般・中等症Ⅱ・重症の確保病床内外は、数値のある都道府県に限定し、調整中のダッシュや報告上のゼロを注記と合わせて扱う。社会福祉施設等療養者は同期間内で26週連続利用可能。期間をまたぐ接続、変数の因果解釈、G-MISとの結合はこの採用判定の対象外。
