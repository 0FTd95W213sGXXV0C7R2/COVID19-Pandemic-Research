## PDF 207件の保存と再取得

元PDF207件をすべて再ハッシュし、公式URL、取得済み版のSHA-256・サイズ、権利表記の探索結果、資料ごとの公開判断を保存した。厚労省のサイト規約とPDL1.0を確認したうえで、PDF本文テキスト・埋込ファイル・ラスター画像を検査した。特記の兆候がなかった206件を**出典表示等を条件とする公開可**、画像要素を含む2020年6月24日資料1件を**画像の個別権利確認まで公開保留**とした。この判定はPDF検査に基づく。第三者著作物の混入や別権利表記が後日判明した場合は、PDL1.0の例外を適用する。今回のGitHub登録はマニフェストと加工データのみ。[厚労省サイト規約](https://www.mhlw.go.jp/chosakuken/) [PDL1.0](https://www.digital.go.jp/resources/open_data/public_data_license_v1.0) [6月24日資料](https://www.mhlw.go.jp/content/10900000/000644284.pdf)

移行用に `/workspace/work/mhlw-originals-private-transfer/` を作成し、`early/` と `weekly/` の207原本と `SHA256_manifest.csv` の整合を確認した。これは作業領域のコピー。永続保管への移行は、当該フォルダ全体を研究機関のアクセス制限付きストレージまたは暗号化した非公開オブジェクト保管先へコピーし、閲覧者・保管期間と復元手順を管理記録に残す。復元先でマニフェストのファイルとSHA-256を照合する。移行先は未指定であり、外部ストレージへのアップロードは未実施。作業領域が失われた場合は、GitHub上のマニフェストとスクリプトの `--restore-missing` を使って同一版を再取得できる。公式URLの版が変わっている場合は、同一版として保存せず、エラーを記録する。

## 報告定義の追加確認

2020年4月の初回調査依頼、2022年9月28日からの報告依頼、2023年5月と10月からの報告依頼、全数届出・医療提供体制の事務連絡、都の会見と議会会議録を取得した。未確定778列出現を照合した結果、**269件の報告定義を確認**した。内訳は以下の通り。

| 区間 | 確認件数 | 項目 |
| --- | ---: | --- |
| 2022-09-28〜2023-05-03 | 128 | 全入院、重症、宿泊、社会福祉施設等（自宅療養者等の内数） |
| 2023-05-10〜2023-09-27 | 63 | 全入院、重症、宿泊 |
| 2023-10-04〜2024-03-27 | 78 | 在院、重症、中等症Ⅱ |

国の重症報告定義は対象のICU相当病床等または人工呼吸器を必要とする者。東京の公開モニタリングは人工呼吸管理・ECMOを基準とする。国の定義を確認した重症79件は定義を記録したうえで、実際の地域別運用が確認できるまで分析保留を維持。10月通知は現段階の即応病床数を確保病床内計上の上限とし、5月通知は確保病床数を上限とする。両期は別の定義IDを使う。[2022年9月報告依頼](https://www.mhlw.go.jp/content/000994201.pdf) [2023年5月報告依頼](https://www.mhlw.go.jp/content/001088884.pdf) [2023年10月報告依頼](https://www.mhlw.go.jp/content/001147068.pdf) [東京都議会会議録](https://www.gikai.metro.tokyo.lg.jp/record/proceedings/2021-1/01.html)

残る509件は保留。初期の使用率の分子と病床の対象、2022年9月以前の施設別自宅療養計数、臨時施設確保定員使用率の分母と同じ対象に限定した分子、自治体ごとの報告仕様が不足する。2022年9月報告依頼の自宅療養推計と直接把握は、それ以前の期間に遡及適用しない。全数届出見直しの事務連絡はHER-SYSの報告を規定しており、週次調査の自宅療養変数への変換根拠には使わない。[初期報告依頼](https://www.mhlw.go.jp/content/000625945.pdf) [全数届出見直し](https://www.mhlw.go.jp/content/000997634.pdf)

分析の入口は従来と同じ `active_crosswalk.json`。有効版をv3に更新し、報告通知の頁・適用期間つき判定を優先する。v2と旧資料は変更していない。歴史版の再生成スクリプトには、v3のポインタを上書きしないチェックを入れた。新規に採用できる190件は、同一定義区分・数値がある地域の記述分析に限る。

## 再現コマンド

Python、PyMuPDF、Popplerの `pdftotext` を使用。各ディレクトリはGit作業ツリー外を指定する。

```bash
python scripts/finalize_mhlw_resource_metadata.py \
  --early-dir /workspace/work/mhlw-early-2020 \
  --later-dir /workspace/work/mhlw-weekly-definition-pdfs \
  --sources-dir /workspace/work/mhlw-final-downloads \
  --private-bundle /workspace/work/mhlw-originals-private-transfer \
  --restore-missing
python scripts/finalize_mhlw_early_series.py --pdf-dir /workspace/work/mhlw-early-2020
```
