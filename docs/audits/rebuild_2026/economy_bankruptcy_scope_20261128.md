# 倒産統計の取得対象追加
記録日時：2026-11-28T11:28:14 JST
ユーザー指定により倒産件数を経済領域の主要指標に指定。2017–2024年、月次を優先。全国・業種・都道府県・規模別件数、負債額、COVID関連倒産、休廃業・解散（別系列）を候補とする。公開範囲に従う。
主系列候補：東京商工リサーチ（負債1000万円以上、法的・私的倒産）。帝国データバンク（同閾値、法的倒産）を比較系列とし混合しない。中小企業庁公表表はTSR由来のため独立検証とはしない。企業数分母が得られれば倒産率も検討。政策効果と感染・物価・支援終了等の影響を区別。
