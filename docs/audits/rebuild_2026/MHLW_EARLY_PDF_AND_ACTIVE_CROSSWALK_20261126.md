# 厚労省の2020年初期PDF取得と分析用クロスウォーク更新

前回コミット `fc95058` からの追加監査。元のExcel、週次時系列CSV、旧クロスウォーク、定義判定表は履歴として保持した。時刻は日本時間で、各マニフェストと検証結果に記録した。

## PDF取得・表の照合

厚生労働省公式アーカイブの取得対象36件をすべて取得。いずれもHTTP 200、PDF形式の実体を確認し、合計19,154,058バイト、SHA-256の異なる36ファイルだった。調査日・公表日・修正日は、公式アーカイブのラベルとPDF本文から得た項目を別欄で保存した。本文の基準日を自動照合できない3件（5/1、5/8、5/13掲載分）は本文欄を不明のままにし、公式アーカイブの表示を残した。5/13掲載PDFは、療養状況と病床等の基準日時が混在する。公表日12件、修正日13件は確認できる表記がなく「不明」とした。[厚生労働省・週次調査アーカイブ](https://www.mhlw.go.jp/stf/seisakunitsuite/newpage_00023.html)

全38ページを画像にレンダリングし、一覧でページと表の配置を点検した。12月16日報告と5月1日病床表は拡大し、見出し・合計行・注記を照合した。12月16日の入院者数10,047、確保病床数27,235は、表示と抽出で一致した。全表について個々のセルを目視転記する代わりに、PyMuPDFで罫線を基に抽出した行と、Popplerのレイアウトテキストを比較した。両方式が47都道府県と全国行で一致する**29表**を一次照合通過とした。セルの結合、都道府県名への脚注付記、並置された参考列などで照合できなかった**9表**は表単位で保留した。通過表もExcel時系列には接続しない。[12月16日の原資料](https://www.mhlw.go.jp/content/10900000/000707318.pdf) [5月1日の原資料](https://www.mhlw.go.jp/content/10900000/000633756.pdf)

通過表の全国行と都道府県を件数の列で照合し、**355件一致、2件保留、不一致0件**。2件は5月21日・5月27日掲載資料の各1列で、都道府県の数値が46件だった。空欄やダッシュを補完せず、率、段階などの非加算項目は対象から外した。4月28日資料の注3では京都府の値が「確認中」の内数で全国合計から除外される。こうした対象外処理が明記された表は、機械的な47都道府県合算で確定しない。[4月28日の原資料](https://www.mhlw.go.jp/content/10900000/000633758.pdf)

## 保留778列出現の追加監査

公式アーカイブで既存Excelと対応するPDFを取得し、**171件すべてでPDF本文の調査日を確認**した。778列出現を同週PDFとExcel脚注に照合し、542件は関連脚注の全文が正規化後に一致した。残りは関係する脚注がない場合と、全文の機械的一致を確認できない場合を含む。この一致は文言照合で、定義確定の根拠の十分性とは別に扱った。全778件を保留し、要確認事項、PDF URL、Excel URL、シート、見出しセル、関係脚注の番号・位置を明細に保存した。

- **初期の病床使用率**。見出しから分母の確保病床を確認。入院確定者を含む公表入院者数が率の分子と同じ集団かは確認できなかった。2021年1月13日注8では東京都の国基準の重症者数と当該確保病床数を単純比較できないと明記。[2021年1月13日PDF](https://www.mhlw.go.jp/content/10900000/000721102.pdf)
- **全入院者と自宅療養**。2021年6月の注は療養者数の内訳を示す。2022年12月の注15は、特定期間の自宅療養等の推計と直接把握による集計を併記する。以前の自宅療養等へ遡って適用できる根拠、全入院者の算入範囲、自治体別の計数方法は未確定。[2021年6月23日PDF](https://www.mhlw.go.jp/content/10900000/000872286.pdf) [2022年12月21日PDF](https://www.mhlw.go.jp/content/10900000/001029801.pdf)
- **重症・中等症Ⅱと臨時施設**。地域別の重症度判定の適用先を確定できず、全期間の接続は保留。臨時施設の注10の療養者合計には、確保病床・居室に位置づけられた施設が含まれる。注11・13の定員と同じ集計対象が注14の分子に対応するかは未確定。[2022年12月21日PDF](https://www.mhlw.go.jp/content/001029801.pdf) [2024年3月27日PDF](https://www.mhlw.go.jp/content/001238243.pdf)

## 分析用メタデータ

有効版の入口は `active_crosswalk.json`。旧クロスウォークのIDを維持し、列別の最新根拠と定義群の採用判定を統合した。週次4,492行、G-MIS 516行を収録。列別の保留を群別採用より優先し、旧ファイルに定義があった72行の保留も維持する。共通の分析ゲートは数値と原表の報告ゼロのみを受け付ける。確定した同一定義ID同士を比較でき、異なる期間区分やG-MISを横断する接続は許可しない。入力または候補CSVのSHA-256が有効版の登録値と異なる場合はエラーとなる。旧版は調査履歴にのみ使用する。

リポジトリ直下で下記を実行する。早期PDFはPyMuPDF 1.26.6とPopplerの `pdftotext` を使用。オフラインでは、検証済みの追加監査明細を使って `--integrate-only` で有効版を再生成できる。取得失敗時もマニフェストにURLとエラーを保存する。

```bash
python scripts/audit_mhlw_early_pdfs.py --private-dir /workspace/work/mhlw-early-2020
python scripts/build_mhlw_current_metadata.py --private-dir /workspace/work/mhlw-weekly-definition-pdfs
```

監査ファイルは `data/audits/mhlw/resource_quality_20261126/early_pdf_audit/`、有効版と候補CSVは `data/metadata/rebuild_2026/scarce_resource/mhlw_resource_quality/` に保存した。
