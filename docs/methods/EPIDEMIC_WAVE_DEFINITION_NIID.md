# COVID-19流行波の判定基準：NIID定義の採用

- 記録日時：2026-11-18 18:13 JST
- 対象：日本版COVID-19流行波の区分（MASTER 03）
- 採用文献：大谷可菜子・神垣太郎・高勇羅・山内祐人・鈴木基「日本における新型コロナウイルス感染症の流行波ごとの性別・年齢的特徴の疫学的検討」IASR Vol.43 p273–275（2022年12月号）
- 原文URL：https://id-info.jihs.go.jp/niid/ja/typhi-m/iasr-reference/11696-514r01.html

## 採用決定

本研究の日本国内の流行波判定では、上記の国立感染症研究所（NIID）の論文に記載された流行波の定義を採用基準とする。従来検討していた本研究独自の「4週・50%基準」は、今回の主判定基準としては採用しない。NIIDの定義を先行研究に基づく基準として明示し、GitHubに登録したデータへ適用する。

## 原文に記載された定義

論文は診断週ごとの流行曲線に基づき、次のように定義している。

- 開始週：「3週以上にわたって増加かつピークの10%以上または2週連続で前週比1.5以上」となった週。
- 終了週：「3週以上にわたって減少かつピークの10%以下（次の波が始まる前まで）」となった週。

対象期間は2020年第3週〜2022年第26週。症例数は診断日基準で集計され、2020年第40週までは自治体が日ごとに公表するCOVID-19関連情報の集計データ、それ以降はHER-SYSデータを使用している。

## 本研究データへの適用

- 分析対象データは、本リポジトリに登録された全国日次新規感染者数 New_cases を使用する。
- 週次集計は月曜日〜日曜日とする。日次7日移動平均系列は波判定に使用しない。
- 欠損値の補間・代入・ゼロ置換は行わない。
- 原文の開始・終了条件を優先し、条件の解釈や境界週の処理を独自に変更しない。
- 論文の対象期間・症例把握方法と本研究データの対象期間・データ由来が異なる部分は、同一であるとみなさず、差異を記録する。

## 不整合が生じた場合

NIID定義を本研究データへ適用した際に、データの定義・集計単位・欠損・期間・波境界の判定などに不整合が確認された場合は、変更点と変更理由を明示した「改正感染研基準」として再定義する。原文の定義と改正後の定義を区別して保存し、改正前後の波数・開始週・ピーク週・終了週への影響を監査する。ユーザーの確認なしに、変更を原文のNIID定義として記述しない。

## 研究上の注意

本論文の定義は同論文の分析上の操作的定義であり、すべての研究に適用される唯一の国の統一基準と表現しない。また、本研究データへの適用時には、原論文とデータ源・対象期間・週次集計方法の違いを方法論上の制約として記載する。
