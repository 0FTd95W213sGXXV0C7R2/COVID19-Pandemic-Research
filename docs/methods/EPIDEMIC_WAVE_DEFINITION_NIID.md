# COVID-19流行波の判定基準：改正感染研基準 v1.0

- 記録日時：2026-11-18 18:20 JST
- 対象：日本版COVID-19流行波区分（全国日次New_cases、2020-01-16〜2023-05-08）
- 原基準：大谷可菜子・神垣太郎・高勇羅・山内祐人・鈴木基「日本における新型コロナウイルス感染症の流行波ごとの性別・年齢的特徴の疫学的検討」IASR Vol.43 p273–275（2022年12月号）
- 原文URL：https://id-info.jihs.go.jp/niid/ja/typhi-m/iasr-reference/11696-514r01.html

## 1. 採用方針

NIID論文の操作的定義を基礎として採用する。ただし、原論文は診断日基準の症例数を用いる一方、本研究のGitHub登録New_casesは厚生労働省の日別新規陽性者数であり、日付・集計ソース・測定方式が同一ではない。実データに原基準をそのまま適用すると、原論文が示す波の終了週の複数が「ピークの10%以下」に達しない。このため、終了条件に限って再現性を確保する補則を加え、「改正感染研基準 v1.0」と定義する。

## 2. 使用データと集計

- GitHubの `data/derived/national_new_cases_daily_20200116_20230508_with_7dMA.csv` を直接使用する。波判定に使う列は原値 `New_cases` のみ。`New_cases_7dMA` は使用しない。
- 週次集計は月曜日〜日曜日。これは国内の感染症発生動向調査で用いる疫学週に合わせる。
- 7日間すべて観測された週だけを採用する。初週の2020-01-13〜2020-01-19（4日分）と最終週の2023-05-08〜2023-05-14（1日分）は不完全週として除外する。
- 欠損補間、ゼロ置換、平滑化は行わない。対象の172完全週に日次欠損はない。

## 3. 開始週の判定（NIID基準を維持し操作を明確化）

- 週次新規陽性者数が3週以上にわたって増加することを必要条件とする。本監査では、開始週を含む3週以上の連続した週次観測で上昇傾向（各週の値が前週を上回ること）を確認する運用とした。これは「3回の週次増加」を要求する解釈（4週以上の観測）とは区別する。
- その増加局面で、(a) 当該波のピーク週の10%以上に到達する、または (b) 前週比1.5倍以上の増加が2週連続する、のいずれかを満たした場合に波の開始を認定する。
- 開始週は、(a) の場合は10%に初めて到達した週、(b) の場合は1.5倍以上の増加が連続した2週のうち最初の週とする。
- ピークは、当該波の区間内で週次新規陽性者数が最大となる週とする。波の途中に小さな再上昇や複数の山があっても、3週連続減少による波の終了条件が成立していなければ同一波内の複数ピークとして扱う。

## 4. 終了週の判定（改正箇所）

原NIID基準は、ピーク後に3週以上連続して減少し、ピーク週の10%以下となった週を終了とする。これを基本条件として維持する。

ただし、本研究のNew_casesで、次の新たな開始条件を満たす波が先に始まり、前波がピーク後3週以上連続して減少しているにもかかわらず10%以下に達していない場合は、10%条件を待たず、次の波の開始週の直前にある局所最小週（谷）を前波の終了週とする。これを「谷による終了補則」とする。

- 10%以下に到達した場合：3週以上連続減少の条件を満たしたうえで、最初に10%以下となった週を終了週とする。
- 次の波が先に開始した場合：3週以上連続減少後の局所最小週を終了週とする。
- データ末尾まで終了条件が成立しない場合：終了未確定（ongoing）とする。

この補則は、原論文の文言そのものではなく、本研究の報告日ベース・測定方式混在系列に適用するための改正である。原NIID定義と混同しない。

## 5. データ定義・出典上の不整合

- 原論文：診断日基準。2020年第40週までは自治体公表情報の集計、それ以降はHER-SYSデータを使用。
- 本研究：厚生労働省 `newly_confirmed_cases_daily.csv` の日別新規陽性者数。GitHubの文献台帳に記録された厚労省注記では、2020-05-08公表分から個票積上げから自治体ウェブ公表値積上げへ変更、2021-09-13以降は報告後14日間を自治体公表値、15日目以降をHER-SYSへ切替、2022-09-27公表分から自治体のHER-SYS総数積上げへ変更された。自治体公表値は必ずしも報告日ベースではない。
- したがって、本研究のNew_casesを診断日基準の原論文データと同一系列とはみなさない。特に2020-05-08、2021-09-13、2022-09-27の測定方式変更を境界として記録し、波の開始・終了の差を直ちに流行実態の差と解釈しない。
- 2023-05-09以降は全数把握の日次公表から週次定点報告へ移行するため、本系列に接続しない。2023-05-08は最終日である。

## 7. 原論文との照合

原論文が報告した6波の期間は、W1: 2020年第13〜20週、W2: 2020年第26〜39週、W3: 2020年第44週〜2021年第8週、W4: 2021年第9〜24週、W5: 2021年第28〜38週、W6: 2021年第51週〜2022年第24週。

本研究データでの開始週はW01・W03・W04・W05・W06が原論文の開始週と一致し、W02は1週後となった。終了週はW02・W03・W04・W06が原論文と一致し、W01・W05は1週後となった。原論文の各終了週に対応する本研究データの週次値は、同じ期間内のピークに対してそれぞれ11.6%、31.2%、16.1%、23.3%、11.3%、15.6%であり、いずれも10%以下ではない。この不一致は、原論文と本研究で使用するデータの診断日／公表日ベースの違い、測定方式の変更等を含むデータ由来の差異と整合するが、原因を単独要因に特定するものではない。

いずれも変更日を含む週の集計値は旧・新の測定方式が週内で混在する可能性がある。日次CSVだけでは、各日の値がどの公表・報告方式に由来するかを完全には再分類できない。したがって、これらの週の値を補正したり、境界を機械的に移動したりしていない。特にW01・W05・W07は、境界の頑健性に関する留保を付して扱う。

### 監査結論

- 9波すべての開始週は、記録した開始トリガーと週次件数に整合した。
- W01〜W08の終了週は、原則の10%閾値または谷による終了補則に整合した。終了週の直後の週次値は全て反転上昇しており、局所的な谷として確認できた。
- W09は終了未確定のまま維持する。
- 3つの測定方式変更日はW01・W05・W07の減少局面またはその直前に重なる。データ定義の差による影響を排除できないため、波境界は「暫定」扱いを維持し、測定方式変更の影響を受けない確定境界とは表現しない。
- 本監査で境界の変更は行っていない。運用文言の「3週以上連続して増加」は原論文の「3週以上にわたって増加」に合わせて明確化し、開始週を含む3週以上の上昇局面として記述した。
