# References and Sources Registry

This file is the canonical bibliography and source register for the COVID-19 Pandemic Research repository.

- Migrated from the Notion database **最終確定版参照文献・参考文献等DB** on 2026-11-18 (JST).
- Records migrated: 66.
- CSV encoding: UTF-8 with BOM.
- One row represents one Notion source record; repeated URLs are intentionally retained when the research roles/notes differ.
- `source_site_name` and `document_title` preserve the Notion source label. When a distinct formal document title was not separately recorded, the source label is retained rather than guessed.
- `authors_as_recorded_or_blank` is populated only when author information is explicit in the source label; otherwise it is blank. Do not infer authors from incomplete metadata.
- Definitions, scope, and research notes are carried over from the Notion record. They are research notes, not a substitute for checking the cited original.
- Access dates preserve the recorded reference date; they do not mean the URL was revalidated on migration date.
- Future bibliography and reference updates must be committed to this repository. Do not use the old Notion database as the ongoing reference register. It remains a historical migration source and should not be deleted.

## Files

- `references_master.csv`: full source register, including source name/title, recorded author information, URL, variables, definitions, notes, target master, and reference date.

## Updating the register

Add a new row for each distinct source record. Preserve exact source URLs, formal title, author list, publication year, DOI, publisher/site, document type, relevant variables, definition/scope, limitations, and access date (JST). If an item is not known, leave it blank and mark the uncertainty in notes. Do not fabricate bibliographic metadata. Keep duplicate URLs as separate rows only when the source role or record is distinct; otherwise update the existing row with an audit trail.
