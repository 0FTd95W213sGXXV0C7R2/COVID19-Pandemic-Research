# 最終研究方針：倫理的問題の軽減策を導く三段階分析

- 確定日：2026-11-19（日本時間）
- 対象プロジェクト：COVID19-Pandemic-Research
- 本文書は、今後の文献調査・データ収集・分析・提言の上位方針とする。

## 1. 研究目的

COVID-19パンデミック時に医療現場で生じた倫理的問題を明らかにし、それらを小さくするために、どのような方策・政策・医療体制を採用すべきかを示す。疫学的状況の記述や指標の収集自体を最終目的とはしない。

## 2. 研究の基本フロー

### Stage 1：倫理的問題を抽出・分類する

文献、医療従事者・患者・家族等への調査、政策資料、報告書から、パンデミック下の医療現場で生じた倫理的問題を抽出する。各問題について、問題の内容、影響を受ける主体、発生した場面、根拠資料、対象期間を整理する。

### Stage 2：疫学データ・政策情報との関連を探索する

Stage 1で特定した倫理的問題ごとに、関連する可能性のある疫学指標、医療資源状況、政策・制度・現場運用の情報を照合する。

分析では以下を区別する。
- 相関・統計的関連
- 時間的な併存・前後関係
- 因果関係（別途、因果推論を支える根拠がある場合に限る）

関連が見られたとしても、データが支えない因果関係は断定しない。指標の定義、分母、対象範囲、集計単位、時間粒度、欠測、測定方法の変更を記録する。政策の発出・存在と、現場での実施・遵守・効果も区別する。

### Stage 3：改善すべき指標・方策を特定し、倫理的に評価する

特定の倫理的問題を軽減するために、改善すべき指標、医療体制、運用、政策を特定する。なぜその改善が倫理的問題の軽減につながると考えられるのか、Stage 2の分析結果と根拠を示す。

改善策は、既存の倫理的評価基準に照らして評価する。少なくとも次の観点を検討する。
- 公平性・正義
- 害の最小化・利益の最大化
- 互恵性
- 自律・自由・患者の意思
- 手続的公正
- 比例性
- 透明性・説明責任

最終成果は、倫理的問題、関連する状況・指標、改善対象、具体的方策、倫理的評価、実施上の限界を一連の論理で示す提言とする。

## 3. 分析・データ管理上の原則

1. 倫理的問題の抽出を出発点とし、取得しやすいデータから研究対象を逆算しない。
2. 疫学指標は倫理的問題そのものではなく、問題の発生・強度・背景と関連しうる説明変数または状況指標として扱う。
3. 定量データ、質的調査、規範的文書を区別し、それぞれが答えられる問いを明示する。
4. 週次・月次データを日次に補間しない。実際の時間粒度のまま分析する。
5. 指標の定義・測定方法・対象範囲が異なる場合は、その差を明記し、安易に同一時系列として接続しない。
6. 観察された関連と、提案する政策の効果予測を区別する。提言の効果が実証されていない場合は、その旨を明記する。
7. 既存の疫学データ収集方針・出典監査・指標仕様は、この三段階の研究設計に従属させ、必要に応じて再整理する。

## 4. 今後の作業順

1. 倫理的問題の一覧を文献・調査に基づいて確定する。
2. 各倫理的問題について、関連しうる疫学指標・政策情報・質的証拠を対応付ける。
3. データの取得可能性と定義の一貫性を監査する。
4. 問題と指標・政策情報の関連を分析する。
5. 倫理的問題ごとに改善対象と方策を導く。
6. 倫理的評価基準を適用し、方策の利点・トレードオフ・限界を評価する。
