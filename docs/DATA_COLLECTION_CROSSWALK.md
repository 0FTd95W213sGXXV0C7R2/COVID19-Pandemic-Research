## 2. 追加で採用する国内面会・家族看護研究

### Clinical Nurses' Attitudes and Self-Reported Practices of Family Nursing in Japan Following COVID-19 Visitation Restrictions (2025)

- 対象：国内4病院の臨床看護師
- 調査依頼：1,921人、回答957人、解析対象892人
- 調査時期：2024年1〜5月
- 変数：家族看護に対する態度、家族との関係・情報収集・コミュニケーション、自由記述による面会制限の影響
- 限界：看護師調査であり、患者・家族本人の回答ではない。4病院の便宜抽出で、パンデミック中の各時点の面会規則を全国的に代表しない。面会制限解除後の影響を含むため、当時の患者心理の直接測定と混同しない。
- URL：https://pmc.ncbi.nlm.nih.gov/articles/PMC12964501/
- PubMed：https://pubmed.ncbi.nlm.nih.gov/41376411/

この研究は面会制限が家族看護実践・職員の認識に残した影響を補足する資料として採用する。Shiraishi et al. (2022)の患者・家族本人の回答、医療機関の面会運用調査と区別して三角測量する。

## 3. データ優先度の最終確定

### 必須（一次分析の中心）
1. 倫理問題の直接証拠：4領域ごとの調査・論文・報告書に記載された件数、経験、判断基準、当事者への影響。
2. 政策・運用情報：対象、期間、規則、例外、実施主体、現場運用。
3. 共通の流行・医療負荷：新規陽性者、新規死亡者、入院患者総数、重症患者総数。ただし、定義・集計方式が接続可能な期間に限定。
4. 領域別の関連データ：
   - 資源配分：ICU・ECMO/MV等の負荷と配分判断調査
   - 面会：面会規則・代替手段と患者/家族/職員への影響
   - 非COVIDアクセス：消防庁の救急搬送困難、医療利用、受診回避・延期
   - 職員負担：感染・欠勤、残業、PPE、心理負担、支援・補償

### 補助（入手・定義を確認できた場合のみ）
- G-MIS週次の新規入院患者数、ICU入院中患者数（7日間平均）、ECMO/MV管理患者数（7日間平均）
- ECMOnet/CRISISの公開集計
- 施設別病床使用率・病床逼迫率。ただし分母、対象施設、即応病床の定義、報告頻度が同じ期間に限る
- Rt。推定法・世代時間・出典接続を監査できる場合のみ
- 職員欠勤の年次データ、患者・家族の追加調査、面会制限解除後の影響調査

### 採用しない
- 日次に補間した週次・月次値
- 定義が異なる系列を無調整で連結した値
- 分母が確認できない病床占有率
- 倫理的問題の直接証拠なしに、感染者数や病床使用率のみで倫理問題を推定した結果
- 研究者・施設への直接照会でのみ得られる非公開情報（本研究では照会しない）

## 4. 実装・分析上の必須メタデータ

すべてのデータ表に、可能な限り次の共通列を持たせる。
- source_id
- observation_date_start / observation_date_end
- published_date
- geographic_scope
- facility_scope
- population_or_respondent_scope
- numerator
- denominator
- value
- unit
- time_granularity
- definition
- collection_method
- missingness_or_revision
- policy_phase
- evidence_type（quantitative / qualitative / normative）
- limitation
- source_locator（URL、表番号、ページ、図番号）

データを統合する際は、日付だけで機械的に結合しない。地域・施設・対象集団・粒度・定義が対応しているかを先に確認する。
